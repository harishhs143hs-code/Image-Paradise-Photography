# Image Paradise Photography — React Application

A modern React SPA rewrite of the Image Paradise Photography web application, built with React 19, TypeScript, and Vite.

## Features Preserved & Ported

- **Interactive Gallery & Lightbox**: Filterable portfolio (Weddings, Portraits, Engagement, Family) with high-res lightbox viewer, touch swipe on mobile, and keyboard navigation.
- **Hero & Cinematic Media**: Promo video with audio mute/unmute control, smooth scroll cues, and achievement counters.
- **Package Selector**: Interactive tier comparison for Essential (₹35,000), Premium (₹75,000), and Luxury (₹1,50,000) packages with direct enquiry pre-selection.
- **Client Testimonials**: Automated testimonial slider highlighting kind words from couples across Chennai and Tamil Nadu.
- **Interactive FAQ Accordion**: Expandable answers for pricing, delivery timelines, candid photography styles, and custom packages.
- **Contact & Enquiry Form**: Complete validation, instant feedback, Web3Forms integration, and direct WhatsApp handoff.
- **Local Landing Pages**: Full support for Chennai, Pre-Wedding, Videography, Ambattur, Avadi, and Tiruvallur routes.
- **Wedding Blog & Guides**: Comprehensive blog listing with category pills and full article reader.
- **Image Paradise AI Assistant**: Floating AI assistant with quick suggestion chips, package comparisons, and smart responses.
- **Mobile Action Rail & Floating WhatsApp**: Seamless mobile call, enquiry rail, and WhatsApp chat button.

## Development

```bash
npm install
npm run dev
```

Server runs on `http://0.0.0.0:3000`.

## Production Build

```bash
npm run build
```
